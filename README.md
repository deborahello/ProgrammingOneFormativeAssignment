# Student Grade and Assignment Tracker

## Project Overview

This is a simple python program for tracking homework and exam grades. The user can add assignments, view them, filter and see grade summary

## Features

1. Add homework
2. Add exams
3. List assignments
4. Filter by subject, type, or month
5. Show overall average
6. Show subject averages
7. Show highest and lowest scores
8. Check invalid scores

## How to run

1. Open the project in VS Code.
2. Run the Python file.
3. Choose an option from the menu.

##  Sample Menu

1. Add homework
2. Add exam
3. List assignments
4. Filter assignments
5. Show summary
0. Exit
